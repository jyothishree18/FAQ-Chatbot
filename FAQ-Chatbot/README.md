# 🤖 FAQ Chatbot using NLP

## Project Description

This project is an NLP-based chatbot that answers user questions by finding the most similar FAQ using **TF-IDF Vectorization** and **Cosine Similarity**.

## Features

- NLP preprocessing
- Tokenization
- Stopword removal
- TF-IDF Vectorizer
- Cosine Similarity
- Flask Web Application
- Responsive Chat UI

## Technologies

- Python
- Flask
- NLTK
- Pandas
- Scikit-learn
- HTML
- CSS
- JavaScript

## Installation

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
